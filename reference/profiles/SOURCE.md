# Происхождение профилей мер

Файлы скопированы без изменений из репозитория «Сканера»:
`azuresong-afk/scanner-way`, каталог `scanner/compliance/profiles/`, коммит `01e035a` (04.11.2026).

- Идентификаторы мер (`ИАФ.1`, `УПД.3`, мероприятия №117 `ВУ`, `КК`, …) совпадают со «Сканером» — по ним приходят автоматические результаты. Менять их нельзя.
- При загрузке в БД все записи получают `origin=scanner`, `verified=null` («требует сверки»): сопоставление «мера → техническая проверка» и применимость мер №21/№239 сделаны разработчиком «Сканера» и методистом не сверены.
- Обновление — через `GET /compliance/profiles` «Сканера» с показом разницы (задача 1.5), а не ручной правкой этих файлов.
